# 바이낸스 자동매매 프로그램 만들기 - 초보자 가이드

## 🎯 프로젝트 목표
바이낸스 선물 거래(BTCUSDT)를 자동으로 하는 프로그램을 만들기

## 📚 현재 단계: 1단계 - 데이터 수집

### 지금까지 만든 것
1. **requirements.txt** - 필요한 라이브러리 목록
2. **download_data.py** - 1년치 1분봉 데이터를 다운로드하는 프로그램

---

## 🚀 실행 방법 (따라하기)

### 1단계: 터미널(명령 프롬프트) 열기

**Windows 사용자:**
- `Win + R` 키를 누르고 `cmd` 입력 후 엔터
- 또는 시작 메뉴에서 "명령 프롬프트" 검색

**Mac/Linux 사용자:**
- 터미널 앱 실행

---

### 2단계: 프로젝트 폴더로 이동

터미널에 다음 명령어를 입력하세요:
```bash
cd /home/user/test
```

---

### 3단계: 필요한 라이브러리 설치

터미널에 다음 명령어를 입력하세요:
```bash
pip install -r requirements.txt
```

**설명:**
- 이 명령어는 필요한 모든 라이브러리를 자동으로 설치합니다
- 몇 분 정도 걸릴 수 있습니다
- 설치가 완료될 때까지 기다려주세요

---

### 4단계: 데이터 다운로드 프로그램 실행

터미널에 다음 명령어를 입력하세요:
```bash
python download_data.py
```

**어떤 일이 일어나나요?**
1. 프로그램이 바이낸스에서 BTCUSDT 1년치 1분봉 데이터를 다운로드합니다
2. 데이터는 `./data` 폴더에 저장됩니다
3. 진행 상황이 화면에 표시됩니다
4. 완료되면 "다운로드 완료!" 메시지가 나타납니다

**시간:** 5~10분 정도 걸릴 수 있습니다 (인터넷 속도에 따라 다름)

---

### 5단계: 다운로드된 데이터 확인

터미널에 다음 명령어를 입력하세요:
```bash
ls -la data
```

**설명:**
- `data` 폴더 안에 다운로드된 파일들을 볼 수 있습니다
- 파일은 CSV 형식으로 저장됩니다

---

## 📊 다운로드되는 데이터 내용

각 1분마다 다음 정보가 포함됩니다:
- **시가(Open)**: 1분 시작 시 가격
- **고가(High)**: 1분 동안의 최고 가격
- **저가(Low)**: 1분 동안의 최저 가격
- **종가(Close)**: 1분 종료 시 가격
- **거래량(Volume)**: 거래된 양
- **거래 횟수**: 1분 동안 발생한 거래 수
- 기타 정보

---

## ❓ 문제 해결

### "pip를 찾을 수 없습니다" 오류
```bash
python -m pip install -r requirements.txt
```

### "권한이 없습니다" 오류 (Linux/Mac)
```bash
pip install --user -r requirements.txt
```

### 인터넷 연결 오류
- 인터넷 연결을 확인하세요
- 잠시 후 다시 시도하세요
